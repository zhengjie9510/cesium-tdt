

# Tianditu 3D Service Integration Code Example

## Supported Cesium Versions
- Cesium 1.120
- Cesium 1.119
- Earlier Cesium versions have not been fully tested

The code can be easily modified to support newer versions, such as Cesium 1.122.

A web server is required to run the project; double-clicking index.html will not display place names.
